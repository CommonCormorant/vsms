# Static Images and User Assets (`client/public/images` & `client/public/usr`)

## 1. Purpose
These directories store static upload indicator images (`images/`) and user asset directory structures (`usr/`).

## 2. Contents
- `client/public/images/`:
  - `img_upload.png`: Icon/graphic for image upload trigger.
  - `img_uploaded.png`: Icon/graphic indicating image upload completion.
- `client/public/usr/`:
  - `img/here.text`: Placeholder marker file establishing user image storage structure.

## 3. Role in VSMS
Provides static graphical indicators for upload features in RetroTerm and establishes placeholders for user-generated content.

## 4. Current State
Static asset directories.
